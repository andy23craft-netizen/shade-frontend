# Bug-Out Bag — Field Kit Build Plan

> **Objective:** Build a self-contained emergency kit that gives me confidence that, if things go badly, I already have what I need.
>
> **Secondary objective:** It should feel like a deliberately assembled field kit hidden away until the day it's needed.
>
> **Rule:** Don't build the whole thing at once. Finish the current phase, assemble it, test it, and enjoy having completed it before moving on.

---

# Phase I — The Pocket Kit

### Mission: Build the first actual piece of the kit.

Keep this phase cheap, fast, and tangible. Everything should fit into a small pouch or organizer.

- [ ] Small utility pouch / organizer
- [ ] Pocket notebook
- [ ] Pens / permanent marker
- [ ] Emergency blanket
- [ ] Waterproof matches
- [ ] Compact flashlight
- [ ] Glow sticks
- [ ] Small amount of paracord
- [ ] Small roll of duct tape

### Field Test

- [ ] Remove everything from its packaging.
- [ ] Organize everything into the pouch.
- [ ] Test the flashlight.
- [ ] Put the pouch somewhere designated for the eventual bag.

> ### 🏁 MILESTONE I — POCKET KIT
> **I now own a compact, self-contained emergency kit.**
>
> The project officially exists. It is no longer a list.

---

# Phase II — The Medical Module

### Mission: Be able to handle ordinary injuries and stabilize more serious ones until professional help is available.

Build this as its own identifiable pouch rather than scattering medical supplies throughout the bag.

- [ ] First-aid pouch / organizer
- [ ] General first-aid kit
- [ ] Saline ampoules / wound irrigation
- [ ] Hemostatic gauze
- [ ] Laceration closures
- [ ] Nitrile gloves
- [ ] Any personal medications or routine medical necessities

### Field Test

- [ ] Remove unnecessary packaging.
- [ ] Organize supplies by purpose.
- [ ] Identify what every unfamiliar item is for.
- [ ] Learn the proper use of specialized supplies before relying on them.
- [ ] Check expiration dates.
- [ ] Label the pouch clearly.
- [ ] Be able to find the major supplies without emptying the pouch.

> ### 🏁 MILESTONE II — MEDICAL
> **I have a dedicated trauma and first-aid module ready to grab immediately.**
>
> One pouch now answers an entire category of emergency.

---

# Phase III — Water & Fire

### Mission: Be able to produce safe drinking water and basic warmth without utilities.

- [ ] Durable water bottle
- [ ] Portable water filter
- [ ] Backup water-purification method
- [ ] Flint / ferrocerium fire starter
- [ ] Waterproof matches
- [ ] Additional emergency blanket if needed
- [ ] Additional paracord / cordage if needed

### Field Test

- [ ] Actually use the water filter.
- [ ] Learn its cleaning/storage procedure.
- [ ] Start a controlled fire with the ferro rod/fire starter in an appropriate location.
- [ ] Start one with the backup matches.
- [ ] Repack everything after testing.

> ### 🏁 MILESTONE III — WATER & FIRE
> **I can independently produce drinkable water and create basic warmth.**
>
> This is no longer just emergency gear. It's becoming a survival system.

**The backpack is the reward for completing the first three modules.**

- [ ] Choose the actual bug-out backpack

- [ ] Larger duct-tape supply
- [ ] Paracord

- [ ] Pack Pocket Kit

- [ ] Pack Water & Fire Module

- [ ] Pack the complete bag.
- [ ] Decide where each module permanently lives.
- [ ] Make frequently needed equipment accessible.
- [ ] Weigh the completed bag.

> ### 🏁 MILESTONE IV — FIELD BAG

# Phase V — Documents & Money

### Mission: Give myself options when normal payment, identification, or information systems aren't available.

- [ ] Money belt / concealed document pouch
- [ ] RFID wallet, if still desired
- [ ] Photocopies of essential identification
- [ ] Printed emergency contact information
- [ ] Important phone numbers written on paper
- [ ] Relevant insurance / medical / account information
- [ ] Waterproof document sleeve
- [ ] Small denominations of US cash

### Cash Reserve

Build this gradually rather than delaying the rest of the kit.

- [ ] $50 emergency cash
- [ ] $100 emergency cash
- [ ] $250 emergency cash
- [ ] Final emergency-cash target established
- [ ] Final target reached
- [ ] Decide whether foreign currency serves an actual emergency scenario
- [ ] Add useful foreign currency only if justified

### Field Test

- [ ] Assume my phone is dead.
- [ ] Assume ATMs/card networks aren't working.
- [ ] Confirm that the documents and information in this module would still let me function.

> ### 🏁 MILESTONE V — PAPER TRAIL
> **I can function without assuming my phone, wallet, internet connection, or banking network is available.**
>
> The bag now contains resources that are useful when infrastructure starts failing.

# Phase VI — Comms & Power

### Mission: Maintain access to information and communications when normal power isn't available.

This is a higher-cost phase. Save for equipment worth trusting rather than buying cheap versions simply to finish the checklist.

- [ ] High-quality power bank
- [ ] Solar charger
- [ ] Charging cables for required devices
- [ ] Wall charger
- [ ] Vehicle charging adapter
- [ ] SIM-card tool
- [ ] Faraday sleeves, if they serve the actual communications plan
- [ ] Define the purpose of a backup/burner phone
- [ ] Backup phone, if justified
- [ ] Appropriate SIM/service arrangement, if justified
- [ ] Written communication plan stored with the kit

### Blackout Test

- [ ] Charge the entire system.
- [ ] Disconnect from household power.
- [ ] Pretend the normal phone is dead or unavailable.
- [ ] Determine what communications remain possible.
- [ ] Recharge a device using only equipment in the kit.
- [ ] Test the solar charger under realistic conditions.
- [ ] Fix any weak points discovered during testing.

> ### 🏁 MILESTONE VI — OFF-GRID COMMS
> **A power outage no longer automatically means losing communications.**
>
> The kit can now support me beyond the first hours of an emergency.

# Phase VII — The Upgrade Pass

### Mission: Replace "good enough" equipment with equipment I genuinely want to own.

This phase can happen slowly. These are satisfying individual purchases rather than obstacles preventing completion of the core bag.

- [ ] Leatherman / quality multitool
- [ ] Keychain pry bar
- [ ] Upgraded flashlight
- [ ] Upgraded compass
- [ ] Better internal organizers / pouches
- [ ] Better cordage
- [ ] Replace any cheap Phase I gear that proved inadequate
- [ ] Identify other frequently used equipment worth upgrading

### Gear Audit

- [ ] Inspect everything currently in the bag.
- [ ] Identify the three weakest pieces of equipment.
- [ ] Upgrade them one at a time.
- [ ] Move replaced but usable equipment into a home/car emergency kit rather than discarding it.

> ### 🏁 MILESTONE VII — FIELD-READY
> **The bag isn't merely complete. It contains equipment I've deliberately chosen and trust.**
>
> At this point, upgrades are refinements—not prerequisites.

---

# Phase VIII — The Gray Pouch

### Mission: Evaluate specialized equipment separately from the core survival system.

Nothing in this phase is allowed to delay completion of Phases I–VII.

Every item has to answer three questions:

**What emergency scenario does this solve?**

**Can I legally possess/carry it where I expect to travel?**

**Do I actually know how to use it safely?**

- [ ] Dedicated Gray Pouch
- [ ] Shemagh / multipurpose cloth
- [ ] Evaluate pepper spray and applicable carry/storage rules
- [ ] Evaluate specialized entry/lock equipment only where lawful and appropriate
- [ ] Evaluate emergency restraint-release equipment only where lawful and appropriate
- [ ] Review any other specialized item from the original wishlist
- [ ] Remove anything whose only justification is "it seems cool"

### Gray-Pouch Rule

- [ ] Every retained item has a defined purpose.
- [ ] Relevant laws/restrictions have been checked.
- [ ] Required training has been completed.
- [ ] Nothing compromises the legality or ordinary usefulness of the main bag.

> ### 🏁 MILESTONE VIII — GRAY POUCH
> **The specialized kit exists as a deliberate, separate module rather than a collection of gadgets.**
>
> The spy shit has now been earned.

---

# Final Mission — Deployment Test

Don't celebrate completion by buying another piece of equipment.

**Use the system.**

- [ ] Pick a weekend.
- [ ] Fully charge relevant electronics.
- [ ] Fill the water container.
- [ ] Grab the bag as though I had to leave immediately.
- [ ] Carry it for several hours.
- [ ] Use equipment from multiple modules.
- [ ] Record everything I wished I had.
- [ ] Record everything I carried but didn't need.
- [ ] Record everything that was difficult to access.
- [ ] Reorganize the bag.
- [ ] Establish an expiration/battery inspection schedule.
- [ ] Choose the bag's permanent storage location.
- [ ] Put it there.

> # 🏆 MISSION COMPLETE — THE CACHE
>
> **There is now one bag, stored in a known location, containing the equipment, information, money, medical supplies, water capability, power, and tools I have deliberately chosen for an emergency.**
>
> I don't need to finish building a bug-out bag someday.
>
> **I have one.**
>
> From here on out, I maintain it.
